# A-Share Double Moving Average Strategy Backtest

一个基于 Python 的 A 股双均线策略回测项目。

本项目使用富耀 API 获取贵州茅台（`600519.SH`）历史日线数据，利用 **5 日均线和 20 日均线**生成交易信号，并完成简单的策略回测、收益统计和结果可视化。

---

## 项目简介

这是一个比较基础的量化回测项目，主要用于实践完整的量化策略流程：

```text
历史行情数据
    ↓
数据获取与处理
    ↓
5日 / 20日移动平均线
    ↓
交易信号生成
    ↓
策略回测
    ↓
收益率 / 最大回撤 / 交易记录
    ↓
结果可视化
```

虽然策略本身比较简单，但项目完整跑通了从**真实市场数据获取到策略回测**的流程。

---

## 策略逻辑

本项目采用经典的**双均线策略（Double Moving Average Strategy）**。

### 参数

* 短期均线：5 日
* 长期均线：20 日
* 初始资金：1,000,000 元
* 回测标的：贵州茅台 `600519.SH`

### 买入规则

当：

```text
5日均线向上突破20日均线
```

生成买入信号。

### 卖出规则

当：

```text
5日均线向下突破20日均线
```

生成卖出信号。

买入时使用当前可用资金尽可能买入整股，卖出时卖出全部持仓。



数据获取后使用 Pandas 进行整理，并以交易日期作为 DataFrame 索引。

## 回测结果

本次使用 2022 年贵州茅台历史日线数据进行回测。

| 指标    |            结果 |
| ----- | ------------: |
| 初始资金  |    ¥1,000,000 |
| 期末资金  | ¥1,101,127.97 |
| 策略总收益 |   **+10.11%** |
| 最大回撤  |   **-19.13%** |
| 交易次数  |            13 |

### 交易情况

回测期间共产生 **13 次交易操作**。

最后一次交易为买入操作，在回测结束时仍然持有仓位，因此没有在最后一天强制平仓。
